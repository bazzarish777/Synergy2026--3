# Synergy2026--3
Практическая работа № 3
Кейс-задача: Нахождение суммы отрицательных элементов одномерного массива

1. Постановка задачи

Дан одномерный массив A, состоящий из N элементов. Необходимо найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива.

Для решения задачи требуется:

ввести размерность массива;

заполнить массив значениями;

определить минимальный и максимальный элементы;

найти индексы этих элементов;

рассмотреть элементы, расположенные строго между ними;

сложить все отрицательные элементы на найденном участке;

вывести полученную сумму.

Результат работы программы — сумма отрицательных элементов, находящихся между минимальным и максимальным элементами массива. Если на этом участке нет отрицательных элементов, сумма равна нулю.

2. Цель работы

Цель данной кейс-задачи — разработать программу на языке C++, которая выполняет обработку одномерного массива, находит его минимальный и максимальный элементы и вычисляет сумму отрицательных чисел, расположенных между ними.

В процессе выполнения задачи используются циклы, условные операторы, стандартные алгоритмы языка C++ и операции над элементами массива.

3. Используемые средства

Для решения задачи используется язык программирования C++.

В программе применяются следующие библиотеки:

iostream — для ввода исходных данных и вывода результата;

vector — для хранения элементов массива;

algorithm — для поиска минимального и максимального элементов.

Также используются:

переменная N для хранения количества элементов массива;

вектор A для хранения чисел;

переменные minIndex и maxIndex для хранения индексов минимального и максимального элементов;

переменные left и right для определения границ рассматриваемого участка;

переменная sum для накопления суммы отрицательных элементов.

4. Алгоритм решения

Решение задачи выполняется последовательно в несколько этапов.

Этап 1. Ввод исходных данных

Сначала программа считывает количество элементов N, после чего пользователь вводит значения массива.

Количество элементов определяет размер создаваемого вектора.

Этап 2. Поиск минимального элемента

С помощью функции min_element() из библиотеки algorithm определяется минимальный элемент массива. Вычитание начала вектора из полученного итератора позволяет определить индекс этого элемента.

Этап 3. Поиск максимального элемента

Аналогичным способом функция max_element() находит максимальный элемент массива и определяет его индекс.

Этап 4. Определение границ участка

Для удобства обработки определяются две границы:

left — меньший из индексов минимального и максимального элементов;

right — больший из этих индексов.

Это позволяет правильно обработать массив независимо от взаимного расположения минимального и максимального элементов.

Этап 5. Вычисление суммы

Программа проходит по элементам массива, расположенным строго между индексами left и right.

Каждый элемент проверяется условием A[i] < 0. Если условие выполняется, значение элемента добавляется к переменной sum.

Минимальный и максимальный элементы не включаются в сумму, поскольку необходимо учитывать только числа, расположенные между ними.

Этап 6. Вывод результата
После завершения цикла программа выводит значение переменной sum.


Подробное объяснение кода

Подключение библиотек

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

В начале программы подключаются необходимые библиотеки. Они обеспечивают возможность работы с вводом и выводом, динамическим массивом и стандартными алгоритмами поиска.

Ввод количества элементов

int N;
cin >> N;

Переменная N определяет количество чисел, которые необходимо обработать.

Создание и заполнение массива

vector<long long> A(N);

for (int i = 0; i < N; i++) {
    cin >> A[i];
}

Создаётся вектор A, содержащий N элементов. С помощью цикла for пользователь вводит значения каждого элемента.

Тип long long позволяет хранить целые числа в более широком диапазоне, чем стандартный тип int.

Поиск индексов

int minIndex = min_element(A.begin(), A.end()) - A.begin();
int maxIndex = max_element(A.begin(), A.end()) - A.begin();

Функция min_element() возвращает итератор на первый найденный минимальный элемент, а max_element() — на первый найденный максимальный элемент.

Вычитая A.begin(), программа получает индекс соответствующего элемента.

Выбор границ

int left = min(minIndex, maxIndex);
int right = max(minIndex, maxIndex);

Функции min() и max() позволяют определить левую и правую границы независимо от порядка расположения крайних элементов.

Накопление суммы

long long sum = 0;

for (int i = left + 1; i < right; i++) {
    if (A[i] < 0) {
        sum += A[i];
    }
}

Переменная sum изначально равна нулю. Цикл начинается с left + 1 и заканчивается перед индексом right. Поэтому крайние элементы не включаются в расчёт.

Условие A[i] < 0 проверяет, является ли текущий элемент отрицательным. Если да, его значение прибавляется к сумме.

Вывод результата

cout << sum << endl;

После завершения вычислений программа выводит итоговую сумму.

9. Оценка сложности алгоритма

Временная сложность — O(N).

Ввод массива, поиск минимального и максимального элементов и вычисление суммы выполняются за линейное время относительно количества элементов.

Пространственная сложность — O(N).

Для хранения исходных данных используется вектор из N элементов.

Таким образом, алгоритм подходит для обработки одномерных массивов различной длины в пределах доступной памяти.

10. Возможные ограничения

В данной реализации предполагается, что размер массива N положительный и входные данные корректны.

Если минимальное или максимальное значение встречается несколько раз, стандартные функции min_element() и max_element() выбирают первое вхождение каждого значения. Если по условию задачи требуется другое правило выбора индексов при повторениях, алгоритм необходимо скорректировать.

В ходе выполнения кейс-задачи была разработана программа на языке C++ для вычисления суммы отрицательных элементов одномерного массива, расположенных между минимальным и максимальным элементами.
Программа выполняет ввод массива, поиск минимального и максимального значений, определение границ рассматриваемого участка, проверку элементов на отрицательность и вычисление итоговой суммы.
Поставленная задача решается с временной сложностью O(N). Решение демонстрирует применение массивов, циклов, условных операторов и стандартных алгоритмов C++ для обработки данных.

Если между минимальным и максимальным элементами нет отрицательных чисел, программа выводит 0.
